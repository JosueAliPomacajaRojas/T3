

## Cómo ejecutar con Visual Studio Code (Live Server)
1. Abre la carpeta del proyecto en Visual Studio Code.
2. Haz clic derecho sobre el archivo 'index.html'.
3. Selecciona "Open with Live Server" (si no lo tienes lo puedes descargar)
4. Se abrirá automáticamente en tu navegador.

## Controles del Juego

**W, A, S, D** | Moverse por la ciudad (Adelante, Atrás, Izquierda, Derecha) 
**Ratón** | Orientar la cámara en primera persona 
**Clic Izquierdo** | Disparar arma activa (1 clic = 1 disparo, sin ráfaga al sostener) 
**Tecla 1** | Seleccionar **Arma 1: Escopeta Táctica** 
**Tecla 2** | Seleccionar **Arma 2: Rifle de Asalto M16**
